This report presents a predictive modeling and optimization workflow for a hypothetical logistics system. It defines shipment delivery duration as a regression target and uses a simulated dataset of 650 shipments containing region, transportation mode, shipment type, route distance, shipment volume, weight, traffic level, weather condition, and actual delivery duration. The workflow prepares numeric and categorical features with a scikit-learn preprocessing pipeline, compares Linear Regression, Decision Tree, Random Forest, and Gradient Boosting models, and evaluates predictions using Mean Absolute Error (MAE), Root Mean Squared Error (RMSE), and R-squared. It uses an 80/20 train-test split, five-fold cross-validation on the training set, and GridSearchCV to tune Random Forest hyperparameters without using the held-out test set for tuning.

The report includes model comparison results and visualizations of test RMSE, actual versus predicted delivery time, prediction-error distribution, and feature importance. It explains what the metrics mean and discusses limitations of synthetic data. It also translates model outputs into logistics optimization strategies, including risk-based shipment monitoring, delivery buffers, transportation mode and cost trade-offs, resource planning, and ongoing model monitoring.

The project package includes the Word report, simulated CSV dataset, reproducible Python training script, saved model artifact, output tables and charts, and an interactive Streamlit dashboard. The dashboard allows users to filter shipments, explore delivery-time and cost trade-offs, and enter shipment characteristics to obtain a model-based delivery-time estimate. All records are simulated for educational use; model performance must be validated on real operational data before business deployment.
